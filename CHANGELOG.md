## [1.0.0-oss] - 2026-09-13

First public open-source release.

- Combined the API and UI into a single MIT-licensed monorepo
- Removed hardcoded SMTP credentials and personal frontend hosts
- Replaced customer brand names with a generic Oak / Pine / Maple catalog
- Renamed the `MANAGER` display label from a customer-specific term to Yönetici / Manager
- Added root Docker Compose, CI, bilingual README, and community files
- Added an optional `demo` Spring profile with sample stores and products
